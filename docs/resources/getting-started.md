# Getting Started

- **Projects** - Programming or other related project that have source material.

## How to Navigate

The docs are pretty simple to navigate. The top navbar can be used to get to the
main sections quickly, while the left sidebar will appear with content inside each
section. When viewing a document, the right side may have a table of contents (ToC).

Generally, once you find the main system you'd like to read, you can use the left
sidebar to read related content, or the right ToC for quick navigation in a document.
